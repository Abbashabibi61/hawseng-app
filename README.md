# هاوسه‌نگ | HAWSENG

**اپلیکیشن مدیریت فروشگاه، کافی‌نت و مشاغل خدماتی** — ساختهٔ «دیجی‌تک» (تکاب)

## هاوسه‌نگ چیست؟

هاوسه‌نگ یک برنامهٔ اندرویدی (همراه با نسخهٔ ویندوز) برای مدیریت روزمرهٔ فروشگاه‌هاست: ثبت سفارش و صدور فاکتور، چاپ و ارسال فاکتور برای مشتری، دفتر نسیه و حساب‌وکتاب مشتریان، باشگاه مشتریان و ارسال پیامک، اسکن بارکد، گزارش فروش و سود، و پشتیبان‌گیری از اطلاعات.

این اپ **کاملاً آفلاین است و اصلاً نیازی به اینترنت ندارد**؛ همهٔ اطلاعات روی گوشی خود فروشنده می‌ماند. نسخهٔ ویندوز آن نیز به‌صورت وب‌اپ در دسترس است.

## پیامک فاکتور هاوسه‌نگ

فروشگاه‌هایی که از هاوسه‌نگ استفاده می‌کنند، پس از ثبت هر سفارش، فاکتور خرید را برای مشتری خودشان با پیامک ارسال می‌کنند (از طریق پنل پیامک فراز). متن آن پیامک شامل نام فروشگاه، شمارهٔ فاکتور، اقلام فاکتور، مبلغ و توضیحات است تا مشتری رسید خریدش را روی گوشی خودش داشته باشد.
